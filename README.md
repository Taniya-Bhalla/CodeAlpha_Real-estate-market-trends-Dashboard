# 🏠 Real Estate Market Trends Dashboard

## 📊 Project Overview

The **Real Estate Market Trends Dashboard** is an interactive **Power BI project** developed to analyze real estate market data and present important property insights through an easy-to-use dashboard.

The dashboard helps users explore property prices, property types, city-wise property distribution, bedroom categories and brokerage-related information using interactive filters and visualizations.

This project was developed as part of my **CodeAlpha Internship**.

## 🎛️ Interactive Filters

The dashboard provides the following slicers:

- **PROPERTY_TYPE**
- **CITY**
- **PRICE**
- **BEDROOM_NUM**
- **BROKERAGE**

These filters allow users to focus on specific property categories, cities, price ranges, bedroom counts and brokerage segments.

---

## 📈 Dashboard Visualizations

The dashboard contains the following major visualizations:

### Property Price by Property Type
Shows the distribution of price records across different property categories.

### Total Property by CITY
Compares the number of property listings across different cities.

### Average Property Price by PROPERTY_TYPE
Compares the average property price for different property types.

### Property Type Distribution
A donut chart showing the percentage distribution of properties by property type.

### Total Properties by PROPERTY_TYPE
Shows the number of properties available under each property category.

### Average Property Price by CITY
Compares average property prices across different cities/localities.

## 🔍 Key Insights

- The dashboard represents approximately **34K properties across 17 cities**.
- **Apartments** are the dominant property category, representing approximately **83.72%** of the displayed distribution.
- **Gurgaon and Hyderabad** appear among the highest-volume cities.
- **Service Apartments** have the highest displayed average property price among the visible property types, at approximately **13.6K**.
- Several **Mumbai localities** appear near the top of the average-price ranking.
- Interactive slicers allow users to perform detailed market segmentation.
